// FAQ
COMMON QUESTIONS.
How many formats does Falcon support? ▼
Falcon supports 360+ distinct image formats including all common web formats, Camera RAW from 20+ brands, medical DICOM, scientific FITS, game GPU textures, GIS satellite imagery, and legacy retro formats. It also recognises 800+ format aliases and variants.
Is Falcon really free? ▼
Yes. 500 conversions per month are free forever with no credit card required. All 360+ formats are available on the free tier. Pro and Studio tiers unlock higher limits, AI upscale, bulk jobs, and the API.
What is PPP pricing? ▼
Purchasing Power Parity pricing adjusts the price based on your country's cost of living. If you're in India, Brazil, Nigeria, or 30+ other countries, you automatically see a discounted price at checkout — no coupon needed.
How does autodetect work? ▼
Falcon reads the first 64 bytes of your file (magic bytes) entirely in your browser — nothing is uploaded until you hit Convert. It matches against a database of 60+ magic byte signatures to instantly identify the format.
Can I convert Camera RAW files? ▼
Yes. Falcon supports RAW files from Canon (CR2, CR3), Nikon (NEF, NRW), Sony (ARW), Fujifilm (RAF), Olympus (ORF), Panasonic (RW2), Pentax (PEF), Hasselblad (3FR), Phase One (IIQ), GoPro (GPR), Leica (RWL), Sigma (X3F), Kodak (DCR, KDC), and Adobe DNG.
Is there a bulk / batch API? ▼
Yes. The Studio tier includes the Bulk API — send a ZIP of up to 10,000 images, get a webhook when they're done. The REST API supports JS, Python, PHP, and curl. See the API docs.
