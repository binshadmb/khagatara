// FAQ
COMMON QUESTIONS.
How many formats does Falcon support? ▼
Falcon supports 360+ distinct image formats — all common web formats, Camera RAW from 20+ brands, medical DICOM, scientific FITS, game GPU textures, GIS satellite imagery, and legacy retro formats. It also recognises 800+ format aliases and variants.
Is Falcon really free? ▼
Yes. 500 conversions per month free forever, no credit card required. All 360+ formats available on the free tier. Pro and Studio unlock higher limits, AI upscale, bulk jobs, and API access.
What is PPP pricing? ▼
Purchasing Power Parity pricing adjusts your price based on your country's cost of living. India, Brazil, Nigeria, and 30+ other countries automatically see a discounted price at checkout — no coupon needed.
How does autodetect work? ▼
Falcon reads the first 64 bytes of your file (magic bytes) entirely in your browser. Nothing is uploaded until you hit Convert. It matches against 60+ magic byte signatures to instantly identify format, brand, and category.
Can I convert Camera RAW files? ▼
Yes. Canon CR2/CR3, Nikon NEF/NRW, Sony ARW, Fujifilm RAF, Olympus ORF, Panasonic RW2, Pentax PEF, Hasselblad 3FR, Phase One IIQ, GoPro GPR, Leica RWL, Sigma X3F, Kodak DCR/KDC, Adobe DNG and more.
Is there a bulk batch API? ▼
Yes. Studio tier includes the Bulk API — ZIP up to 10,000 images, POST once, get a webhook on completion. REST API supports JS, Python, PHP, and curl. See the API docs.
