Quickstart

Four calls to output

01

Create an upload URL.

02

Put the source file.

03

Start a conversion job.

04

Download the result.

curl -X POST https://api.khagatara.com/v1/convert \
  -H "Authorization: Bearer $FALCON_API_KEY" \
  -F "file=@input.heic" \
  -F "output=jpg" \
  -F "quality=92"
